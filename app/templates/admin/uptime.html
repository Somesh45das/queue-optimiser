Monitoring endpoints

Point an external uptime service at these URLs to satisfy the 99.5% target from continuous outside observation:

EndpointPurposeFrequency
/health Cheap liveness ping. Returns 200 as long as the process serves HTTP. Every 1–5 min
/health/ready Deep readiness. Verifies DB + ML, records a sample. Returns 503 if unavailable. Every 5 min
/health/uptime 30-day summary in JSON. On demand

Recommended free monitors:

  • UptimeRobot — 50 monitors free, 5-min interval
  • Better Stack Uptime — 30s interval on free plan
  • StatusCake — 5-min interval, unlimited HTTP tests free

Self-hosted samples in this dashboard cover in-process failures; an external monitor is required to detect process crashes or network issues from outside the server.
