## 🎬 Animations Added

### Entrance Animations
1. **slideUp** - Card slides up with scale (0.6s)
2. **slideInLeft** - Features slide from left (0.6s each)
3. **fadeIn** - Demo box fades in (0.6s)
4. **slideDown** - Alerts slide down (0.4s)

### Continuous Animations
1. **backgroundMove** - Background moves (20s loop)
2. **float** - Shapes float and rotate (20s loop)
3. **rotate** - Gradient rotates (30s loop)
4. **pulse** - Icon pulses (2s loop)
5. **bounce** - Icon bounces (2s loop)

### Hover Animations
1. **Role cards** - Lift and scale (8px up, 1.05 scale)
2. **Login button** - Lift with ripple effect
3. **Register button** - Lift and gradient fill

### Loading Animation
1. **Spinner** - Rotating spinner on button (0.6s)
