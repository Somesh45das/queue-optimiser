## 🔧 How to Use

### 1. The CSS is Already Applied
Just refresh your browser to see the changes!

### 2. Use Utility Classes
```html
<div class="card glass-effect hover-lift">
    <h5 class="gradient-text">Cool Card</h5>
</div>
```

### 3. Customize Colors
Edit CSS variables in `style.css`:
```css
:root {
    --primary: #your-color;
}
```

### 4. Add Animations
Use animation classes:
```html
<div class="fade-in">Content</div>
```
