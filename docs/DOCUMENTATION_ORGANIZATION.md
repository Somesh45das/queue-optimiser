When adding new documentation:

1. Create the markdown file in the `docs/` folder

3. Update this file if needed
4. Link from README.md if it's a major document

## 📝 File Naming Convention

Documentation files follow these naming patterns:

- **Guides**: `*_GUIDE.md` (e.g., `DEPLOYMENT_GUIDE.md`)
- **Summaries**: `*_SUMMARY.md` (e.g., `IMPLEMENTATION_SUMMARY.md`)
- **References**: `*_REFERENCE.md` (e.g., `QUICK_REFERENCE.md`)
- **Fixes**: `*_FIX*.md` (e.g., `WHITE_SCREEN_FIX.md`)
- **Features**: `*_FEATURE.md` (e.g., `APPOINTMENT_HISTORY_FEATURE.md`)
- **Complete**: `*_COMPLETE.md` (e.g., `RBAC_SYSTEM_COMPLETE.md`)
