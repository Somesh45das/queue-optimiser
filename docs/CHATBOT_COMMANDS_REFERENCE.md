# 🤖 Chatbot Commands Quick Reference

## 👤 Patient Commands

| Command | What It Does | Example |
|---------|-------------|---------|
| `hello`, `hi` | Start conversation | "Hello" |
| `book appointment` | Start booking process | "I want to book an appointment" |
| `check status` | Check appointment status | "Check my appointment status" |
| `estimated time` | Get appointment timing | "What's my estimated time?" |
| `precautions` | Get preparation advice | "Precautions for cardiology" |
| `find doctor` | Search for doctors | "Find a cardiologist" |
| `wait time` | Get current wait times | "What's the wait time?" |
| `departments` | View all departments | "Show me departments" |
| `crowd info` | Get crowd predictions | "When should I visit?" |
| `help` | Show available commands | "Help" |

---

## 🎯 Quick Tips

### For Patients:
- 📱 Provide phone number for status checks
- 🏥 Mention department for specific precautions
- 👨‍⚕️ Specify specialty when finding doctors
- ⏰ Check estimated time before leaving home

### For Management:
- 📊 Check queue stats regularly
- 🚨 Monitor high-risk patients
- 📈 Review department performance
- 📉 Use crowd forecast for planning
