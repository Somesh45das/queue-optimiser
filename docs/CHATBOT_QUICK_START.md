# 🤖 Chatbot Quick Start Guide

## What is the Chatbot?

The SmartCare Hospital Chatbot is your AI assistant that helps with:
- 📅 Booking appointments
- 🔍 Checking appointment status
- 👨‍⚕️ Finding doctors
- ⏱️ Getting wait time estimates
- 🏥 Viewing departments
- 📊 Checking crowd predictions

## How to Use

### 1. Open the Chatbot
- Look for the **purple chat button** in the bottom-right corner
- Click it to open the chat window

### 2. Start Chatting
Just type naturally! The chatbot understands:
- "Hello"
- "I want to book an appointment"
- "Find me a cardiologist"
- "What's the wait time?"
- "Check my appointment status"
- "Show me departments"
- "When should I visit?"

### 3. Use Quick Suggestions
- Click on suggestion buttons for quick actions
- No need to type - just click!

## Example Conversations

### Book an Appointment
```
You: "Book an appointment"
Bot: Shows available departments
You: Click "Cardiology"
Bot: Shows available doctors
You: Click "Book with Dr. Smith"
```

### Check Status
```
You: "Check my status"
Bot: "Please provide your phone number"
You: "9876543210"
Bot: Shows your appointments
```

### Find a Doctor
```
You: "Find a cardiologist"
Bot: Shows cardiologists with ratings
You: Click "Book with Dr. Smith"
```

### Get Wait Times
```
You: "What's the wait time?"
Bot: Shows current wait times for all departments
```

## Tips

💡 **Be Natural**: Just type like you're talking to a person
💡 **Use Suggestions**: Click buttons for faster navigation
💡 **Ask for Help**: Type "help" to see what the bot can do
💡 **Be Specific**: Mention department or specialty for better results

## Supported Commands

| Command | What it Does |
|---------|-------------|
| "hello", "hi" | Start conversation |
| "book appointment" | Start booking process |
| "check status" | Check appointment status |
| "find doctor" | Search for doctors |
| "wait time" | Get current wait times |
| "departments" | View all departments |
| "crowd info" | Get crowd predictions |
| "help" | Show available commands |
| "thanks", "bye" | End conversation |
