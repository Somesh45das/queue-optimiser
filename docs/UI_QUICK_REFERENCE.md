## 🔧 Customization

### Change Primary Color
```css
:root {
    --primary: #your-color;
}
```

### Change Sidebar Width
```css
:root {
    --sidebar-width: 280px;
}
```

### Change Animation Speed
```css
:root {
    --transition-base: 0.5s ease;
}
```
